《解放西的夏天》
文旅活动策划

把一档综艺 IP 的线上热度，落到一条能走、能玩、能消费的城市路线里。

  • 前期调研梳理长沙本地景点与特色旅游资源，实地踩点，结合游客动线与活动条件，为路线规划提供依据。
  • 机制设计参与“景点打卡 + 集邮 + 优惠券 + IP 周边”机制，串联“IP 吸引 → 线下打卡 → 权益领取 → 旅游消费”的完整体验路径。
  • 内容策划参与“偶遇解放西”核心概念与传播内容，用偶遇事件制造自然话题点，增强游客参与与社交传播。
  • 落地推进参与路线规划、方案优化及执行，推动方案从前期调研、创意构思走到具体执行。

《守护解放西》
导演助理

在拍摄现场，把稍纵即逝的信息，变成后期能用的素材。

  • 现场记录记录关键人物、重要事件、时间节点及核心情节，及时整理拍摄素材，为后续内容筛选与制作提供依据。
  • 信息筛选按节目内容需求快速筛选、重点标记，提炼具有叙事价值和节目表现力的关键细节。
  • 素材梳理协助导演整理素材与拍摄内容，配合现场流程推进，确保重要信息完整记录。
  • 协同推进与导演、摄制组及现场工作人员保持沟通，及时反馈关键信息，提升现场传递与执行效率。

02 / HOW I WORK

我的工作方法

不是“想出一个点子”，而是把一个点子送到它该去的地方。

  1. 01

    先下去看

    实地踩点、收集素材、和现场的人聊。判断不从二手信息里来。

  2. 02

    再拆机制

    把创意拆成参与者能理解的步骤：从哪来、做什么、得到什么、为什么愿意分享。

  3. 03

    推到落地

    路线、物料、流程、沟通，一项项盯到方案真正发生，而不是停在 PPT 里。

  4. 04

    最后沉淀

    复盘踩过的坑，写成模板、清单和文档，让下一次少走一遍弯路。
